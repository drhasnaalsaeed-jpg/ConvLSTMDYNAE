# Dataset Setup

Raw datasets are not included in this repository.

## London Smart Meter Dataset

Download the London Smart Meter dataset from its official source and place
the required files in:

    data/london/

## Irish CER Dataset

Obtain the Irish CER smart-meter dataset through its authorized source and
place the required files in:

    data/irish/

The preprocessing scripts will generate local cache files when executed.
Cache files and processed datasets are excluded from Git.
